# AI将棋 Pro

「どうぶつしょうぎ」と「将棋」をひとつにまとめた、モバイル優先のブラウザーアプリです。Liquid Glassに着想を得た半透明のナビゲーションと、読みやすさを優先した落ち着いた盤面を採用しています。

## 起動

GitHub PagesなどのHTTPS対応の静的ホスティングに `index.html`、`manifest.json`、`sw.js` を配置してください。PWAインストールとService WorkerはHTTPS（またはlocalhost）で動作します。

## 実装済み

- どうぶつしょうぎと本将棋の切り替え
- どうぶつしょうぎ：移動、捕獲、持ち駒、ひよこの成り、トライ判定
- 将棋：初期配置、移動、成り、持ち駒、基本的な王手回避、打ち歩・二歩・行き所のない駒の一部制約
- 対局中の待った、新しい対局、手動対局モード
- AIの簡易着手評価、AIレベル・考慮時間の設定
- iPhone向けレスポンシブUI、アクセシブルな操作ラベル、ローカル設定保存、PWAシェル

## 制限

本リポジトリは動作するフロントエンドのプロトタイプです。将棋AIはランダム性を含む軽量な一手評価で、強豪レベルの棋力・「レベル100」の強さを保証しません。YaneuraOu/WASM、NNUE、WebGPU推論モデルは含みません。オンライン対局、6桁ルーム、ランキング、ユーザー識別子はサーバーと安全な認証・通信基盤が必要なため未実装です。オンライン機能を使えるように見せかける識別子やランキングデータは生成しません。

将棋の完全な公式ルール実装（王手放置・千日手・連続王手の千日手・打ち歩詰め等）や棋譜形式、エンジン連携は別途検証・実装が必要です。対局前にルール上の重要な局面を確認してください。

## 設計方針

AppleのLiquid Glassガイダンスを参考に、ガラス表現は下部ナビゲーションや設定ボタンなどの操作レイヤーに限定し、盤面や本文には使わずコントラストを保っています。動きの軽減・透明度を抑える環境設定も考慮しています。
